# 1.3.0 — Mobile V1 workspace (development preview)

Native phone presentation now uses a compact project header, aspect-preserving preview, playback controls, flexible timeline, floating Add button and scrollable contextual navigation. Importing content no longer permanently reserves a tiny panel below the timeline: a resizable bottom sheet opens over the lower workspace without changing the project or playhead.

Shape, Media, Audio and saved Elements use the existing project services. Eighteen vector shape presets can be inserted as editable overlay objects. Text uses a real input dialog; Captions currently means manual text. Shape/text-only projects can render and export through ICE Lite. Older shape IDs, saved project fields, package identity and the existing DeX workspace are preserved.

Retains existing trim/move/split/duplicate operations, undo/redo, thumbnail/waveform loading, transform controls, snapping, timeline zoom, project saving and export. Removes overlapping empty-timeline guidance and keeps Compare accessible in the selected-layer panel.

Not included: freehand strokes, node-editable paths, template library, automatic caption generation, arbitrary project aspect ratios, or unlimited tracks. These features must not be inferred from the reference artwork. See the QA record for qualification status and remaining limitations.

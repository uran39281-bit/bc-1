# Replace a person (experimental)
Select a video layer, then **Media Settings → Layer Tools → Character Swap**. Choose one transparent, full-body PNG, tightly framing a humanoid in a front-facing T-pose. Choose a clean still of the same empty scene (same framing, orientation, aspect ratio and lighting), or choose **Use first frame** if the shot starts empty. The whole source file must fit the limits even if the timeline clip is trimmed.

The first implementation targets one full-body performer filmed by a stationary camera. It is a 2D puppet: it cannot generate unseen views, preserve moving objects that cross the performer, or infer a hidden background. Chibi proportions, turns, and overlapping limbs can distort. It is not a general video diffusion model.

The ARM64 Android app runs MediaPipe Pose Landmarker Lite locally. It replaces pixels inside the person mask with the supplied background and deforms a textured mesh using the detected joints. No server, model download on the phone, or training is needed. The build fetches the model from the Google MediaPipe model bucket (float16/1, SHA-256 pinned); for a local build asset pass -Pbc1PoseModelFile=/path/to/pose.task. Model source: https://ai.google.dev/edge/mediapipe/solutions/vision/pose_landmarker

The result is a new private H.264 video. Both previews and exports read that video, with its original frame timestamps and original AAC audio packets. Existing edits continue to apply. The original file is untouched and Undo restores it. Cancel, failed detection, an unsupported file, or leaving the editor discards the unfinished result. Rendering is bounded to short SDR footage: up to 12 seconds, 360 frames, even dimensions, and the pixel count of 720p, with one AAC track or no audio. No automatic GPU/CPU speed claim is made.
